{%- comment -%} jekyll-theme-cayman's default layout includes this file inside , which is the only hook it offers — the theme ships no favicon of its own, so without this the docs site falls back to the browser's blank-page glyph. The icon is an inline SVG data URI rather than an asset file: it needs no extra request, no binary committed to the repo, and cannot 404. The flag reads at 16px, and #159957 is Cayman's own header-gradient green, so the tab matches the site it opens. SVG favicons are ignored by Safari and older Edge, which fall back to /favicon.ico; there is deliberately no .ico here, so those browsers keep their default glyph. That is an accepted trade rather than an oversight — committing a binary to dodge it is not worth it for a docs site. {%- endcomment -%}
